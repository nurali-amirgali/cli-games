# CLI GAMES
cli games is a collection of some short classic games that runs directly in your brother and can be served over ssh. 

## HOW TO RUN
### copy this command, paste it in your terminal and run
```
ssh -p 2222 guest@2a01:4f9:3080:3192::2078
```
alternativly you may run the python file (main.py) directly.

## HOW TO PLAY
- Use the arrow keys to navigate the menu. 
- All games support wasd or arrow keys
- click Q at anytime to quit the game

## CURRENTLY INCLUDED GAMES
- Pong
- Snake
